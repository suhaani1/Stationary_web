# Sri Radha Vallab Agency

Sri Radha Vallab Agency is a modern MERN stack stationery e-commerce website developed for managing and selling stationery products online. The website provides a user-friendly shopping experience where customers can browse products, add items to cart, place orders, and contact the agency easily.

---

##  Features

### User Features
- User Registration & Login
- Browse Stationery Products
- Product Categories
- Add to Cart
- Remove from Cart
- Order Placement
- Contact Form
- Responsive Design
- Search Functionality

### Admin Features
- Admin Dashboard
- Add Products
- Update Products
- Delete Products
- View Customer Messages
- Manage Orders
- Product Image Upload

---

##  Tech Stack

### Frontend
- React.js
- Vite
- CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Other Tools
- Git & GitHub
- Postman
